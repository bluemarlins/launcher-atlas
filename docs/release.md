# 검증과 릴리스

## 공개 전 체크

- 새 경로에서 세 APK 빌드·test·lint 및 동시 설치 확인
- HOME 선택/취소/기존 홈 복귀, 앱 설치/제거/실행/검색
- grid·dock 이동, 충돌 교환, 폴더 생성/이름변경/항목 꺼내기/제거
- 프로세스 재시작·재부팅·업데이트 후 사용자 grid·배치 보존
- 배경 적용 가능/불가·이미지 누락·미설치 앱 fallback
- 글꼴 확대·대비·모션 축소, 페이지 전환 성능
- Pixel·Galaxy 실기기 각 1종의 OS·기기·결과·확인일 기록
- 실제 기기 9:16 동작 영상과 스크린샷, 이미지·폰트 배포조건 확인

현재 체크리스트는 검증 완료 선언이 아니다. 에뮬레이터 결과와 실기기 결과를 분리해 기록한다.

## 버전·서명

`applicationId`를 유지하고 업데이트 시 `versionCode`를 증가시킨다. 서명키를 생성·백업하고 같은 키로 APK를 서명한다. 비밀번호는 로컬 환경변수로 전달하며 로그·Git에 기록하지 않는다. debug APK는 release APK로 배포하지 않는다.

공개 태그는 `paper/v1.0.0` 형식이다. GitHub Releases에 실제 서명 검증된 APK, SHA-256, 변경 사항, 검증 기기·OS·알려진 한계를 첨부한다. Google Play 배포는 후속이다.

## 영상 기본 구성 (15–25초)

1. 0–3초: 완성 홈 화면과 작품 이름
2. 3–10초: 페이지·폴더·앱 실행 실제 조작
3. 10–17초: 스타일·아이콘 확대
4. 17–22초: 무료 APK와 소스가 있는 GitHub 링크 안내

AI로 대본과 자막을 제안할 수 있다. 실제 APK에 없는 동작을 합성해 시연하지 않는다. 조회수·저장·링크 클릭·star 변화는 날짜별 실제 값으로 기록한다.
